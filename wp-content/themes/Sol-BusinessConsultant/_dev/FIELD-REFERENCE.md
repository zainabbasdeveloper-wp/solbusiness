# SOL child theme — SCF Field Reference

Generated by `_dev/build/build.mjs`. Every field group, repeater, sub-field and data type in the Sol-BusinessConsultant child theme.

Read values with `get_field()` / `have_rows()` (SCF uses the ACF API). Site settings: `get_field( 'name', 'option' )`.

Link fields accept checkout tokens: `woo:sku:SKU` or `woo:id:123` add the product to the cart and open checkout; `woo:product:123` opens the product page.
