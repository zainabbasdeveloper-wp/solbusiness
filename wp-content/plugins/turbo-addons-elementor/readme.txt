== Installation ==

Follow these steps to install Turbo Addons for Elementor on your WordPress website:

1. **Download the Plugin:**
   - Download the `turbo-addons-elementor.zip` file from the [WordPress plugin repository](https://wordpress.org/plugins/turbo-addons-elementor/).

2. **Upload the Plugin:**
   - Log into your WordPress admin dashboard.
   - Navigate to `Plugins` > `Add New`.
   - Click `Upload Plugin` and select the `turbo-addons-elementor.zip` file.
   - Or search on searchbar using keywords with "Turbo Addons Elementor" then click installl.

3. **Activate the Plugin:**
   - Once the installation is complete, click `Activate` to enable the plugin.

== How to Use Turbo Addons for Elementor ==

1. **Add a Widget:**
   - Open any post or page in the Elementor editor.
   - In the Elementor widget panel, locate the **Turbo Addons** category.
   - Drag and drop the desired widget to your section.

2. **Customize Widget Settings:**
   - Click on the widget to open its customization panel.
   - Adjust design, layout, and functionality options as needed.

3. **Publish or Update:**
   - After making the desired changes, click `Publish` or `Update` to save.

== Frequently Asked Questions ==

= Is Elementor Pro required to use Turbo Addons? =

No, you can use all the Turbo Addons widgets with the free version of Elementor. Some advanced features may work better with Elementor Pro.

= Where can I get support for Turbo Addons for Elementor? =

For assistance, please visit [our support page](https://turbo-addons.com/contact/) or ask questions via the WordPress support forum.

= Can I use Turbo Addons on multiple websites? =

Yes, Turbo Addons for Elementor is licensed under GPL v2 or later, allowing you to use it on unlimited websites.

= How do I install Turbo Addons for Elementor? =

Install it like any WordPress plugin  go to Plugins > Add New, search for `Turbo Addons for Elementor`, click Install, then Activate. Elementor must be installed and active.

= Will Turbo Addons slow down my website? =

No. Turbo Addons only loads the CSS and JS for widgets that are actually used on the page, keeping your site fast and lightweight.

= Is Turbo Addons compatible with all WordPress themes? =

Yes, Turbo Addons works with any WordPress theme that supports Elementor.

= Do I need coding knowledge to use Turbo Addons? =

Not at all. Everything is drag-and-drop inside Elementor. No coding required.

= Does Turbo Addons work with WooCommerce? =

Yes. Turbo Addons includes widgets designed to work alongside WooCommerce, such as product displays, carousels, and promotional elements. You can build fully functional WooCommerce-powered pages using Elementor and Turbo Addons together.

= Can I display WooCommerce products using Turbo Addons widgets? =

Yes, several Turbo Addons widgets support dynamic WooCommerce data, allowing you to showcase products, categories, and pricing directly in your Elementor layouts.

= What is the difference between the free and Pro versions of Turbo Addons? =

The free version includes 50+ widgets covering a wide range of use cases. Turbo Addons Pro unlocks additional premium widgets, advanced styling options, and priority support. You can upgrade at [turbo-addons.com/pricing](https://turbo-addons.com/pricing/).

= How do I upgrade to Turbo Addons Pro? =

Visit [turbo-addons.com/pricing](https://turbo-addons.com/pricing/), choose a plan, and follow the checkout process. After purchase you will receive a license key and the Pro plugin to install alongside the free version.

= Will my existing design break if I upgrade to Pro? =

No. The Pro version is an add-on that works alongside the free plugin. All your existing widgets and designs remain intact after upgrading.

= Is there a refund policy for Turbo Addons Pro? =

Yes. Turbo Addons Pro comes with a 14-day money-back guarantee. If you are not satisfied, contact support within 14 days of purchase for a full refund.
